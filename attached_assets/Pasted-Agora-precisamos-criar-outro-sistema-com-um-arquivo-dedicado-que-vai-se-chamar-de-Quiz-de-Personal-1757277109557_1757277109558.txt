Agora precisamos criar outro sistema com um arquivo dedicado, que vai se chamar de "Quiz de Personalização"!

Esse componente vai ser uma nova página com uma interface dedicada, que vai aparecer assim que o usuário criar a sua conta dentro da plataforma, ou seja, assim que o usuário criar uma nova conta dentro da plataforma, o usuário não vai ser redirecionado para a interface de login, ele vai ser redirecionado para essa interface de Quiz de Personalização instantaneamente!

Faça a seguinte organização, um arquivo de Flow que cuida das páginas do quiz, e coordena os redirecionamentos, e faça uma interface dedicada para cada etapa desse quiz! E depois do usuário passar por todas as etapas desse quiz ele vai ser redirecionado para a interface principal da plataforma, na interface da seção de Painel, logado diretamente da sua conta!!!!!!!

A interface das etapas do Quiz de Personalização vão ser as seguintes:

Etapa 1: Uma interface com um titulo centralizado, no topo, com o texto de "Um app envolvente e feito com uma abordagem baseada na ciência para derrotar o vício na pronografia para sempre.", abaixo desse primeiro texto, vai ter um outro texto maior e em negrito, que vai ser de "7 bilhões de horas", e como um subtitulo vai ter um texto de "são disperdiçadas todos os anos assistindo pornografia somente no Brasil!", e abaixo desse texto, vai ter mais 3 textos representados por icones, em fileira vertical, esses 3 textos serão: (Tempo suficiente para construir 700.000 Cristos Redentores), (Tempo suficiente para explorar a floresta amazônica inteira 800.000 vezes!) e (Tempo suficiente para escalar o monte Pão de Açúcar 3.5 bilhões de vezes!), abaixo desses textos vai tere um botão de "Continue", com o mesmo estilo do card retangular de Assitente IA (De dentro da interface de Painel), ao clicar nesse botão a interface atualizada para a próxima interface da etapa 2!!!!!!!

Etapa 2: Uma interface com um titulo em negrito centralizado, no topo, de "Você não está sozinho!", e abaixo desse titulo, vai ter outro titulo um pouco menor, de "Encontros diários com a comunidade de soldados."! Abaixo desse texto, vai ter um card flutuante com um efeito 3D, inclinado um pouco para esquerda! Dentro desse card vai ter no topo dele um titulo de "Só hoje já salvamos 317 pessoas do vício maldito." Faça que o texto de "317", vai ficar crescendo progressivamente! Faça que abaixo desse titulo, tenha um componente composto por 5 componentes circulares, um circulo ao lado do outro, e os circulos vão estar configurados para guardar imagens no futuro!!!!!!! Abaixo desse card vai ter um botão de "Continue", com o mesmo estilo do card retangular de Assitente IA (De dentro da interface de Painel), ao clicar nesse botão a interface atualizada para a próxima interface da etapa 2!!!!!!!
