2. API de Acesso à Câmera

O acesso à câmera é feito com a WebRTC API (navigator.mediaDevices.getUserMedia).

Exemplo em React:

import { useEffect, useRef } from "react";

export default function CameraCard() {
  const videoRef = useRef<HTMLVideoElement>(null);

  useEffect(() => {
    async function initCamera() {
      try {
        const stream = await navigator.mediaDevices.getUserMedia({
          video: { facingMode: "user" }, // "user" = câmera frontal
          audio: false,
        });
        if (videoRef.current) {
          videoRef.current.srcObject = stream;
        }
      } catch (err) {
        console.error("Erro ao acessar a câmera:", err);
      }
    }
    initCamera();
  }, []);

  return (
    <div className="rounded-2xl shadow-lg p-4 bg-white">
      <h2 className="text-lg font-bold mb-2">Câmera Ativa</h2>
      <video
        ref={videoRef}
        autoPlay
        playsInline
        muted
        className="w-full rounded-xl"
      />
    </div>
  );
}

3. Considerações Técnicas

Performance:
O streaming é local (não sobe pro servidor a não ser que você capture). Impacta apenas CPU/GPU.

Privacidade:
Sempre mostrar aviso claro pedindo permissão da câmera. Permissão deve ser explícita e revogável.

Fallback:
Caso o usuário negue o acesso, renderize mensagem (“Permissão da câmera negada”).

Cross-Platform:
Em apps mobile (React Native, Flutter), use plugins específicos:

React Native: react-native-camera ou react-native-vision-camera.

Flutter: camera package.
